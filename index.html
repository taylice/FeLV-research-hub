Sobre os PDFs: este site publica apenas os metadados e o link oficial de cada referência (DOI ou página da editora), não os arquivos PDF em si. A maioria dos artigos científicos tem direitos autorais das editoras, e redistribuir o PDF publicamente não é permitido mesmo quando o acesso original foi legítimo (ex: via portal de periódicos institucional).

About the PDFs: this site only publishes the metadata and the official link for each reference (DOI or publisher page), not the PDF files themselves. Most scientific articles are copyrighted by their publishers, and this holds even when the PDF was obtained legitimately (e.g. via an institutional journal portal).
